# 🍔 API Restaurante - FastAPI

Projeto de API REST desenvolvido com FastAPI, SQLAlchemy e SQLite.

## 🚀 Funcionalidades

- Cadastro de clientes
- Criação de pedidos
- Atualização de status do pedido
- Listagem de clientes e pedidos

## 🛠️ Tecnologias

- Python
- FastAPI
- SQLAlchemy
- SQLite

### ▶️ Como rodar

```bash
pip install -r requirements.txt
uvicorn main:app --reload
